Keyboard shortcuts

Misket is built to be used without reaching for the mouse. This page mirrors src/core/keymap.ts — every action the app binds a chord to, for both macOS and Windows/Linux. In the app itself, open this same reference any time with Ctrl/⌘+/.

A test in the app's own repository (src/core/keymap.test.ts) checks that every action listed here still appears on this page, so this table cannot silently go stale as shortcuts change.

The document view numbers its paragraphs in the left gutter (turn it off under Ctrl/⌘+,), remembers where you had scrolled to in each document, and lets you rename the open document by double-clicking its title or pressing F2.

Moving excerpt boundaries

Alt + arrows moves the focused excerpt's end edge; adding Ctrl/⌘ moves the start edge instead, and adding Shift steps by one character rather than one word. The end edge's character step is the one exception to that rule — it drops Alt, because Alt+Shift+arrows already extends the selection (above). You can also drag the round grips at either end of the focused excerpt with the mouse.
