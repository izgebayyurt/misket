Transcription

Misket turns a recording into a transcript on your own machine, with Whisper. No account, no upload, no per-minute bill. The audio never leaves the computer it is sitting on, which for interview data is usually the only arrangement an ethics approval will accept.

Get a model first

Nothing is bundled. Whisper needs a model file, the smallest useful one is 75 MiB and the best is 1.5 GiB, so Misket does not guess which one you want or download it behind your back. Open Settings → Transcription and press Download next to one:

Model Size When to pick it
Tiny / Tiny (English) 75 MiB Fastest and roughest. Good for finding out whether this works on your audio.
Base / Base (English) 142 MiB Still quick. Usable for clean, close-miked speech.
Small / Small (English) 466 MiB The usual choice for interview audio on a modern laptop.
Medium 1.5 GiB Noticeably better on accents and crosstalk; several times slower.
Large v3 Turbo 1.5 GiB The best on offer, and nearly as fast as Medium.

The English-only variants are smaller for the same accuracy on English and cannot do anything else. The rest handle around a hundred languages and can translate to English.

Each file comes from the ggerganov/whisper.cpp repository on Hugging Face — the same one whisper.cpp's own download script uses — and is checked against the SHA-1 that project publishes before it is put in place. An interrupted download resumes where it stopped. Models live in Misket's app data folder, which Settings shows in full, and Delete takes one away again.

On a machine with no network, copy a ggml-*.bin across on a stick and use Add model file…. Misket checks that the file really is a ggml model, and says plainly that it has no published checksum to compare a hand-added file against.

Transcribing

Right-click a recording in the document list — or use the Transcribe… button in the player's toolbar — and choose:

  • Model, from the ones you have downloaded.
  • Language: detect it from the first thirty seconds, or name it. Naming it is a little faster and a little more reliable.
  • Translate to English, Whisper's second task: the transcript comes out in English whatever was spoken. Multilingual models only.
  • Paragraphs: one per segment as Whisper cuts them, or grouped into paragraphs of at least fifteen seconds, thirty seconds or a minute. Longer paragraphs read better; shorter ones give you more precise timestamps to click.
  • Timestamps: open each paragraph with [mm:ss].

The run happens in the background — a progress bar with the percentage, the number of segments so far and a rough estimate, and a Stop button that really does stop it. You can keep coding other documents while it runs. It uses one fewer thread than your machine has by default, so the rest of the desktop stays usable; Settings can change that.

What you get

A new text document called <recording> (transcript), one paragraph per segment: 

[00:00] So tell me how you first heard about the programme.

[00:06] It was through a friend, actually. She had been
going for about six months by then.

It is an ordinary document: immutable text, code it with the same palette and hotkeys, export it with everything else. Because it carries its timestamps, Misket lines it up with the recording automatically — clicking a passage seeks the player, and coding a stretch of audio highlights the matching text. The whole thing is one step in History, so a single Ctrl/⌘+Z takes the transcript and the link back together.

Speakers

Misket does not label speakers here, and will not pretend to. Whisper transcribes; it does not do diarisation — working out who is talking — and guessing from pauses would put a guess into your data where a coder would read it as a fact. What you can do is edit the exported transcript into Name: turns in a text editor and re-import it, which the speaker-aware transcript features then pick up properly.

Formats, and when you need ffmpeg

Audio needs nothing installed. Misket decodes mp3, wav, m4a, aac, ogg and flac itself, and reads the audio track out of most mp4, m4v, mov, mkv and webm video on its own too.

For a video container it cannot open — an unusual codec, an exotic wrapper — it falls back to ffmpeg if there is one on your PATH. So video transcription may need ffmpeg installed; audio never does. Settings says so when it cannot find one, and the Transcribe dialog warns before you start.

How long it takes

Roughly: Tiny runs many times faster than real time on any recent laptop, Small is around real time or better, and Medium and Large v3 Turbo are slower than real time on a machine with no GPU acceleration. A one-hour interview with Small is a coffee break, not an overnight job. The estimate in the progress dialog is measured from how far along it actually is, not guessed from the file size.

For people building Misket

Transcription is an optional Cargo feature (whisper), on by default. It builds whisper.cpp from source, so a release build needs CMake and a C++ toolchain. A build made with --no-default-features compiles without either and says, in place of the dialog, that this build has no transcription support.
