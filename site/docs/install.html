Install Misket

Builds for macOS, Windows and Linux are published on the releases page. They are not code-signed yet, so each platform's gatekeeper will warn you the first time you open the app — that is expected, not a sign anything is wrong. Once installed, Misket checks for updates on launch and offers to install them in place; turn this off, or check manually, under Settings.

On this page

macOS

  1. Download the .dmg (or .app.tar.gz) from the releases page and drag Misket into Applications.
  2. Open it. Because the app is not signed with an Apple Developer certificate, Gatekeeper will refuse to launch it and may say it is "damaged" or "from an unidentified developer".
  3. Go to System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to the Misket message. Confirm in the dialog that appears. You only need to do this once per release.

If macOS does not show an "Open Anyway" button, right-click (or Control-click) the app in Finder and choose Open, then confirm in the dialog.

Windows

  1. Download the .msi installer from the releases page and run it.
  2. Windows SmartScreen will show "Windows protected your PC" because the installer is not signed by a recognised publisher yet.
  3. Click More info, then Run anyway. This only appears on the first run of a new release.

Linux

Misket publishes an AppImage and a .deb package.

AppImage

chmod +x Misket-*.AppImage
./Misket-*.AppImage

Marking the file executable is required because most desktops download files as read-only.

Debian / Ubuntu (.deb)

sudo dpkg -i misket_*.deb
# if it reports missing dependencies:
sudo apt-get install -f

Build from source

Prerequisites: Node 22, pnpm 10, Rust stable, and the Tauri prerequisites for your OS. 

git clone https://github.com/izgebayyurt/misket.git
cd misket
pnpm install
pnpm tauri dev          # run the app with hot reload
pnpm check              # lint + typecheck + vitest
cargo test --workspace  # database and domain logic tests
pnpm tauri build        # installable bundle for this platform

See the README's macOS-from-scratch section for exact rustup/nvm/pnpm setup steps, and docs/ARCHITECTURE.md for how the pieces fit together.
