Assistance

Misket can ask a language model for suggestions. It is off. It stays off until you go to Settings, choose a provider and tick a box — and even then it never applies anything. Every suggestion is something you accept by clicking it, and every one you accept is recorded as yours, with a note saying you had help.

Why it works this way

Researchers who have used AI coding in other tools report the same complaint: it made choices I did not agree with, and it was hard to tell afterwards which decisions were theirs. That is not an argument against help; it is an argument against silent automation and against losing the audit trail. So Misket draws the line in one place: a model can propose, only a person can decide, and the project file remembers which is which.

  • Nothing is applied, created or saved without a click.
  • Accepting a suggestion goes through the same commands as coding by hand — same coder, same undo step, same weight defaults. There is no separate "AI coding" path.
  • The history entry says assisted: true with the provider and model, while the actor stays you. A year later you can still tell which codings were drafted and which were not.
  • A code id the model invents is dropped rather than applied. A reply that is not valid JSON is no suggestions, not an error.

The three features

Suggest codes for a selection

Select a passage and press Suggest on the selection toolbar, or in the excerpt inspector. Up to five chips come back, each with its reason on hover and a confidence. Clicking a chip applies that code to the passage. A + chip is a code that does not exist yet: it opens the ordinary code dialog with the name filled in, and you still have to press Create.

Summarise a code's excerpts

Select a code and press Summarise… in the right-hand panel. A memo draft — themes, quotations cited by excerpt id, tensions between them — streams in and is editable from the first character; there is a Stop button while it is arriving. Save it as a memo or discard it. What is saved is whatever is in the box when you press Save, and the memo's body carries a line saying it was drafted with assistance, because a memo gets exported and read long after the history log is out of sight.

Draft a definition

In the code dialog, Draft definition fills the description, "Include when" and "Exclude when" fields from the passages already coded with that code. It is offered only for a code with at least three excerpts: below that there is nothing to generalise from, and the draft would be the model's guess about the code's name — exactly the quiet wrong answer this feature exists not to give. The fields stay editable and nothing is written to the project until the dialog's Save.

Providers, including one on your own machine

Two shapes are supported: Anthropic's Messages API, and anything that speaks the OpenAI chat API. The second covers far more than OpenAI — Ollama, LM Studio, llama.cpp, vLLM, a university gateway. The Local (Ollama) preset fills in http://localhost:11434/v1 and needs no key; with it, assistance costs nothing and still sends nothing over the network, which may be the only arrangement your ethics approval allows.

Your API key is stored in your operating system's credential store — Keychain on macOS, Credential Manager on Windows, Secret Service on Linux — never in Misket's settings file and never inside a project. On a machine with no usable credential store the key is kept in memory for that session only, and Settings tells you so rather than pretending it saved.

What gets sent

Feature What leaves your machine
Suggest codes The selected passage (up to 4,000 characters), one paragraph either side of it (up to 1,000 characters each), and your code names with their definitions — up to 200 codes; past that, the ones whose wording is closest to the passage.
Summarise a code Up to 40 excerpts carrying that one code, with the document names they came from, and the code's own name and definition.
Draft a definition The same excerpts, for one code.

Never a whole document. Never the project file. Never your memos. Never anything at all for a feature you have not switched on. Long text is cut to the limits above, and the prompt says so where it was cut rather than quietly pretending that was all there was.

The prompts are four short functions in src/core/assist/prompts.ts, with tests, so you can read every word Misket would send before you turn anything on.

The audit trail

Settings → Assistance → Show what was sent lists every request this session: the time, the feature, the provider and model, how many bytes went out and how many came back. It holds sizes, never content, so it is safe to show a colleague or a research ethics committee. It covers the session and is not written to disk.

In the project itself, the History view shows each accepted suggestion as an ordinary step with two extra fields: Assisted: yes and the provider and model that drafted it. The activity CSV export carries them too.
